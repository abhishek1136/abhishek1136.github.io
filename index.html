WHOOP
WhatsApp AI Coach

A personal AI fitness coach that lives in WhatsApp. Every morning at 7 AM it automatically syncs biometric data from WHOOP — recovery score, HRV, sleep stages, strain, and workout history — and sends an intelligent coaching briefing. The agent learns from every conversation: corrections, goals, injuries, and preferences are stored permanently and shape every future response.

03 · Coach

04 · Learn
Every correction and goal is detected and saved. Agent gets smarter over time.

NSE India
Market Analysis Agent

A fully automated daily stock analysis agent built for swing trading on Indian markets. Every weekday at 8:30 AM, GitHub Actions runs a Python pipeline that fetches live prices for 50 Nifty stocks, computes RSI, MACD, Bollinger Bands, Moving Averages, and volume signals — then sends the data to Claude AI, which ranks all stocks by momentum and writes a plain-English brief with the top 5 buy picks, each with an exact entry range, stop loss, price targets, and shares to buy. Results hit your inbox and update a live dashboard automatically. Zero infrastructure cost.

01 · Fetch
yfinance pulls 90 days of OHLCV data for 50 NSE stocks. No API key. No cost.
02 · Score
RSI, MACD, MA20/50/200, Bollinger Bands, and volume ratio computed. Each stock gets a momentum score 0–100.
03 · Rank
Claude AI reads top 15 candidates and picks 5 highest-conviction swing trades with entry, stop loss, and targets.
04 · Deliver
Formatted HTML email sent via Gmail. data.json pushed to GitHub Pages. Dashboard auto-refreshes.
